# Fundiora Utility Map — Public-Safe Draft

## One-sentence candidate

Fundiora is a proof-first project control room: a place where project status, evidence, decisions, and next actions become visible enough for a team/community to inspect before anything becomes a public claim.

## What it can be used for now

- **Clarity:** turn scattered work into a single readable project surface.
- **Evidence gating:** prevent unsupported public claims by routing statements through source/owner/review gates.
- **Demo readiness:** give outsiders a safe way to see progress without exposing private ops or secrets.
- **Team alignment:** make the next choices explicit: what to build, what to verify, what to avoid saying.
- **GitHub-visible progress:** show real branch/commit/PR work instead of private-only artifacts.

## What it can become

- **Public trust layer:** a clean public site that shows verified status and boundaries.
- **Project operating dashboard:** a control room for roadmap, artifacts, reviews, and decisions.
- **Holder/community information surface:** only after exact access, benefits, and evidence language are verified.
- **Agent-assisted project studio:** Aurel/Paperclip-style workers produce drafts, scans, review packets, and UI prototypes; humans approve public moves.

## What must stay blocked until evidence/approval

- Any holder rewards, yield, staking, financial return, token-price, or listing language.
- Any partner/endorsement language.
- Any wallet signing, funding, transaction, OAuth-write, or onchain execution.
- Any public/admin/social send that has not been reviewed.
