# Public Safety Boundaries

This packet is designed for a public GitHub branch or draft PR. It intentionally excludes:

- API keys, provider tokens, browser cookies, OAuth tokens, private keys, seed phrases, wallet secrets;
- local absolute user-home paths or machine-specific filesystem details;
- internal admin-chat excerpts;
- private partner/listing/investor claims;
- unverified token utility, reward, staking, yield, or market claims;
- commands that mutate wallets, OAuth write scopes, social accounts, or external services.

## Allowed in this packet

- Static HTML/CSS/Markdown demo material.
- Public-safe project positioning.
- High-level utility hypotheses clearly framed as drafts.
- GitHub workflow metadata, branch names, and review checklists.

## Approval required before next stage

- Merging to `main` if it changes the public default branch.
- Enabling GitHub Pages or publishing any public/shareable live URL.
- Sending the link to Fundiora admins, partners, or public social channels.
- Adding any claims about rewards, staking, holder benefits, listings, partners, or live wallet/onchain actions.
